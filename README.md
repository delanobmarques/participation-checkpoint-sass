# PROG2700 Client-Side Programming — SASS Participation Checkpoint

In today’s in-class activity, we will:
1) Follow the SASS docs together to build a **simple webpage** using SASS.  
2) Build out a **full demo** (the same features shown in class), including variables, mixins, and a small UI.  
3) Submit your **latest commit ID (hash)** on Brightspace.

> **Important:** This repo contains only starter files. You will **create the project files** locally during class and commit your work as you go.

---

## ✅ What you will learn

- Install & use the **Live Sass Compiler** (VS Code extension)
- Create a SASS project structure with partials (`_variables.scss`, `_mixins.scss`)
- Use **variables**, **nesting**, and **mixins**
- Transpile SASS → CSS and include it in `index.html`
- Add a small JavaScript interaction (`main.js`)
- Make clean, incremental Git commits

---

## 🧰 Requirements

- **VS Code**
- **Live Sass Compiler** extension (Glenn Marks)
- **Git** installed and configured
- A web browser (Chrome/Edge/Firefox/Safari)
